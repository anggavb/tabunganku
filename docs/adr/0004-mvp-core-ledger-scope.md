# MVP Core Financial Ledger Scope

We considered whether to implement full RPG gamification (XP, character levels, badges) and collaborative shared jars in the initial release. We decided to restrict the MVP scope to the core financial ledger (Jars, Quests, Deposits, Withdrawals, Transfers, Repayments, Categories, Recurring Transactions) with lightweight RPG visual styling. The financial ledger and balance calculations must be rock-solid before introducing game reward mechanics and multi-user collaboration.
